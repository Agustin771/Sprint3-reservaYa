🚀 reservaYa — Sprint 3
¡Seguimos metiéndole a reservaYa! 💪

En este Sprint 3 incorporé nuevas funcionalidades, mejoras en la experiencia de usuario y manejo de errores, con persistencia en base de datos. También sumé tests tanto en el backend como en el frontend para asegurar que todo funcione como corresponde.

✨ ¿Qué hay de nuevo?
❤️ Sistema de favoritos: incorporé una sección de favoritos con persistencia en la base de datos.
🗂️ Gestión de categorías: los usuarios administradores pueden eliminar categorías, siempre y cuando no tengan productos asociados. Si una categoría contiene productos, el sistema informa por qué no se puede eliminar y muestra cuántos productos tiene.
🛠️ Acceso a administración: agregué un botón de acceso al panel de administración, visible únicamente para usuarios con rol de administrador.
📅 Rango de fechas para servicios: incorporé la selección de rangos de fechas para consultar los productos disponibles dentro de un período determinado.
💾 Persistencia de datos: las nuevas funcionalidades mantienen la información almacenada en la base de datos.
🛡️ Manejo de errores: sumé validaciones y mensajes para manejar distintas situaciones y brindar una mejor experiencia de usuario.
🧪 Tests
¡También hubo lugar para las pruebas!

Incorporé tests tanto en el backend como en el frontend, y en mi última revisión estaban pasando todos correctamente. ✅

La idea es seguir mejorando la estabilidad del proyecto y detectar posibles problemas antes de que lleguen al usuario.
